Privacy policy

posta is used only by its owner, for the owner's own mailbox. It reads messages received since its previous run (at most the last 72 hours) with the read-only scope gmail.readonly. Each message is sent to the Anthropic API (Claude) to get a category and a one-sentence summary. The resulting overview is kept on the owner's own server only until it is delivered to the owner's own Telegram chat, then deleted. No Google user data is shared with or sold to anyone else, used for advertising, or used to train AI models.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
